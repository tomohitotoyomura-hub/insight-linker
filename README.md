# Insight-Linker

Insight-Linker is a small CLI tool for **insider risk triage**.  
It combines user activity logs, HR context, and access privileges to highlight potentially risky events.

This is an MVP project to practice how infrastructure-style logs, HR information, and access controls can be stitched together into an explainable insider risk view.

---

## Project Structure

```text
.
├─ app/
│  ├─ __init__.py
│  ├─ core_engine.py      # Risk scoring logic
│  ├─ loader.py           # JSON → dataclass loaders
│  ├─ models.py           # Domain models (UserActivity, HRContext, AccessPrivilege, EvaluationResult)
│  └─ report_gen.py       # Markdown report generator
│
├─ data/
│  └─ raw/
│     ├─ access_privileges.json
│     ├─ hr_context.json
│     └─ user_activity.json
│
├─ outputs/
│  └─ (generated) YYYYMMDD_HHMMSS_insight_report.md
│
└─ main.py                # Entry point
```

- `app/` contains all Python modules for loading data, evaluating risk, and generating reports.
- `data/raw/` contains sample JSON data used for the MVP.
- `outputs/` contains Markdown risk reports generated by `report_gen.py` (one file per run).

---

## Features

- Load sample data for:
  - **User activity** (file access events)
  - **HR context** (leave / resignation status)
  - **Access privileges** (allowed resource paths)
- Score each activity as **Low / Medium / High** risk
- Attach human-readable **reasons** to each decision
- Return results as an `EvaluationResult` dataclass
- Generate a Markdown report summarizing **Medium / High** risk events

---

## Tech Stack

- Python 3.x
- `dataclasses` for modelling domain objects
- JSON files as sample data inputs
- Simple rule-based scoring logic
- Markdown report generation

## Getting Started

### 1. Clone this repository

```bash
git clone https://github.com/tomohitotoyomura-hub/insight-linker.git
cd insight-linker
```

### 2. (Optional) Create and activate a virtual environment

Example with `venv`:

```bash
python -m venv .venv
# Windows (PowerShell)
.venv\Scripts\Activate.ps1
# macOS / Linux
source .venv/bin/activate
```

### 3. Install dependencies

If you add a `requirements.txt` later, install like this:

```bash
pip install -r requirements.txt
```

*(For this MVP, the standard library may be enough if no external packages are used.)*

### 4. Run the main script

From the project root:

```bash
python main.py
```

This will:

- Load sample JSON data from `data/raw/`
- Evaluate each activity and compute risk scores
- Print results to the console
- Generate a Markdown report under `outputs/`
  - e.g. `20260504_073214_insight_report.md`

## Why I built this

I have 7+ years of experience in IT infrastructure operations and I am transitioning toward  
**insider risk, security operations, and GRC (governance, risk, and compliance)** roles.

Insight-Linker is a personal MVP project to:

- Practice modelling simple insider risk scenarios
- Combine infrastructure-style activity logs with HR and access context
- Produce explainable, auditable risk scores and Markdown reports

The code and structure are intentionally kept small and explicit so that the logic is easy to read and extend.
